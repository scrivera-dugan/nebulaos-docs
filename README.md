# NebulaOS Docs

Documentation for **NebulaOS**, a hosted documentation platform for software teams.

This is the source for docs.nebulaos.dev. Pages are written in Markdown and
organized by `SUMMARY.md`.

## Local development

```bash
nebula dev
```

## Contributing

Every doc needs a `title` and a `description` in frontmatter. Run
`nebula lint` before opening a pull request.
