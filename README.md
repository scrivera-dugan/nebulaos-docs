# Larkspur Docs

Documentation for **Larkspur**, a hosted documentation platform for software teams.

This is the source for docs.larkspur.dev. Pages are written in Markdown and
organized by `SUMMARY.md`.

## Local development

```bash
larkspur dev
```

## Contributing

Every page needs a `title` and a `description` in frontmatter. Run
`larkspur lint` before opening a pull request.
