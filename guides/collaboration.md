# Collaboration

## Change requests

A change request bundles edits across one or more pages. Reviewers see a
rendered diff rather than raw Markdown.

## Comments

Comments can be anchored to a block. Resolving a comment does not require
maintainer permissions.

## Roles

| Role | Can edit | Can review | Can publish |
|---|---|---|---|
| Reader | No | No | No |
| Author | Yes | No | No |
| Maintainer | Yes | Yes | Yes |
| Admin | Yes | Yes | Yes |

## Notifications

Authors are notified when a review is requested on a page they own, and when
a change request touching their pages is merged.
